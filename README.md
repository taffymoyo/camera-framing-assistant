# Camera Framing Assistant

An accessible web tool that helps blind and low-vision users frame a photo, built with VoiceOver support and keyboard-friendly navigation.

**Live demo:** https://taffymoyo.github.io/camera-framing-assistant/

## What it does

- Uses the device camera to help line up a shot
- Gives spoken and screen-reader-friendly feedback on framing
- Works with VoiceOver and keyboard-only navigation, with logical tab groupings

## Run it locally

No build step or dependencies. From the repo folder:

    python3 -m http.server

Then open http://localhost:8000 in your browser.

## Tech

- HTML, CSS and JavaScript
- Hosted on GitHub Pages

## Accessibility

Tested with macOS VoiceOver. If you hit an accessibility problem, please open an issue.
